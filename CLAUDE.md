# newsletter-saved-items

Personal tool: things saved from X, Instagram, the web and the camera roll become Items, get an AI Summary in Polish, and go out as a daily Digest email. Design docs: `CONTEXT.md` (glossary), `docs/adr/` (decisions), `docs/spec.md` (v1 parameters).

## Agent skills

### Issue tracker

Issues live in GitHub Issues of `kubek93/newsletter-saved-items`, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
