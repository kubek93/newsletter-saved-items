# Every Item is pushed from the Owner's device; no platform API is polled

All Items enter through one path: an iOS/macOS Shortcut on the Share Sheet that sends a bare URL (X post, Instagram post, web page, YouTube) or a file (photo, video) to the app's ingest endpoint, authenticated with a single static token. No X bookmarks sync, no Instagram sync. Reasons (2026-09-26): Instagram has no API for saved posts at all; X bookmarks are readable via a paid pay-per-use API but need a developer account, OAuth PKCE with token refresh and a polling job, for roughly five bookmarks a day. Post content is resolved server-side from the URL (FxTwitter for X, Apify for Instagram, Jina Reader for pages, Gemini directly for YouTube). Considered: polling X bookmarks (rejected as infrastructure for one saved gesture); revisit if the Share Sheet gesture proves annoying.
