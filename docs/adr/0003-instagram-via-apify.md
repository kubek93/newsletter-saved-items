# Instagram content is read through Apify, not an official Meta API

Instagram Items arrive as a bare post URL. Meta offers no API that returns a post's caption or media for a URL without App Review; tokenless oEmbed returns only an embed skeleton (verified 2026-09-26). The unofficial `/embed/captioned/` page works for photos but gives no video file for Reels, and the Owner wants Reels analysed as video. So post data (caption, author, image and video URLs) is fetched with an Apify Instagram scraper actor, paid per result (about 0.5 to 2.7 USD per 1000 posts). Considered: HikerAPI (similar, rejected by Owner preference), the embed page alone (no Reels video), headless Chrome (hits Instagram's login wall from datacenter IPs). Consequence: this dependency can break or be blocked at any time; when it fails the Item still reaches the Digest with its link and a "could not read" note.
